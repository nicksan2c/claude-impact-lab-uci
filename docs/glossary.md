# Glossary

Plain-language meanings for terms you will hear today. Where a term has a source, it is linked.
Where a definition is general industry usage with no source here, it is marked (general).
Check the source before you rely on a law.

## Money

| Term | Meaning |
|---|---|
| **AMI** | Area Median Income. The middle household income for an area. Programs set limits as a percent of it (for example 80% AMI). The numbers come from a published table and differ by program. [HCD State Income Limits](https://www.hcd.ca.gov/grants-and-funding/income-limits) and [HUD USER](https://www.huduser.gov/portal/datasets/il.html). Use the latest revision (HCD's 2026 State limits were revised June 23, 2026) |
| **Income limits** | The table that says how much a household of a given size can earn and still qualify. State, State HOME and HUD each publish their own |
| **Lower income** | A household category tied to income limits. Defined in [Health and Safety Code 50079.5](https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=HSC&sectionNum=50079.5) |
| **Affordable housing cost (ownership)** | The most an owner household in an income category should pay for housing, under [Health and Safety Code 50052.5](https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=HSC&sectionNum=50052.5). The event brief puts it around 30 to 35 percent of income |
| **Pencil, "does it pencil"** | The numbers work. Money in covers the cost |
| **Pro forma** | A projected budget for a project: costs, income and funding (general) |
| **Gap** | Cost to create the home minus what the buyer can pay. The rest must come from other sources |
| **Capital stack** | The layers of money that pay for a project, such as a first mortgage, city and state loans, grants and donations (general) |
| **Silent second** | A second loan behind the first mortgage with no required payments until a later event, such as a sale or refinance (general). Terms vary by program |
| **Shared appreciation loan** | A loan repaid with a share of the home's later increase in value. [CalHFA Dream For All](https://calhfa.ca.gov/dream/) is a program of this kind. Check whether it has funds |
| **Down-payment assistance (DPA)** | Money that helps a buyer cover the down payment. City, state and bank programs exist. See Lane 3 data |
| **CalHome, CalHFA, HOME, CDBG** | Public funding programs. See [Lane 3 data](../lanes/3-fund-it/data/DATA-SOURCES.md) |
| **Community land trust (CLT)** | A nonprofit that owns land and sells the home on it to a buyer, with resale limits that keep it affordable. See [Grounded Solutions Network](https://groundedsolutions.org/strengthening-neighborhoods/community-land-trusts) |
| **Shared equity** | Resale rules that split a home's value gain between the owner and the program (general). See Grounded Solutions |
| **CRA** | Community Reinvestment Act. Federal law pushing banks to lend in the communities they serve. [OCC page](https://www.occ.treas.gov/topics/consumers-and-communities/cra/index-cra.html) |
| **CDFI** | Community development financial institution. A lender focused on underserved communities. [CDFI Fund](https://www.cdfifund.gov/programs-training/programs/cdfi-program) |

## Land and approvals

| Term | Meaning |
|---|---|
| **Entitlement** | The approvals a project needs from a city before it can get building permits, such as zoning and design approval (general). About a year in the event brief's four-year path |
| **Rezoning** | Changing what the zoning allows on a parcel. About a year in the four-year path |
| **Ministerial** | If you meet the written rules, the city must say yes, with no hearing and no discretion |
| **Discretionary** | The opposite: officials can weigh the project and may say no or add conditions, often after a hearing (general) |
| **By-right** | Allowed without a discretionary approval, if the project meets the rules. Close to ministerial in practice |
| **Objective standard** | A rule that can be checked without judgment, such as a setback in feet. SB 9 lets cities apply some. See [HCD SB 9 fact sheet](https://www.hcd.ca.gov/sites/default/files/docs/planning-and-community/lot-splits-and-duplexes-sb-9.pdf) |
| **Parcel, APN** | A parcel is a legal lot. APN is its Assessor Parcel Number |
| **GIS** | Geographic information system. Maps and map data |
| **General plan, zoning** | A city's long-term land-use plan and the rules that apply lot by lot (general) |
| **Overlay zone** | An extra set of rules layered on a base zone (general) |
| **Surplus Land Act** | Law requiring local agencies to offer surplus land for affordable housing and publish notices. [HCD page](https://www.hcd.ca.gov/planning-and-research/public-lands/surplus-land) |
| **Notice of Availability (NOA)** | The notice an agency sends when it offers surplus land. Published as data on data.ca.gov |
| **Excess state land** | State-owned sites screened for housing under Executive Order N-06-19. [HCD page](https://www.hcd.ca.gov/planning-and-research/public-lands/excess-state) |
| **ADU, JADU** | Accessory dwelling unit, and junior ADU. A small extra home on a lot. Rules in Gov Code 66310 to 66342, renumbered from 65852.2. [HCD ADU Handbook](https://www.hcd.ca.gov/sites/default/files/docs/policy-and-research/adu-handbook-update.pdf) |
| **Pre-approved plan** | A city-approved design an applicant can use to speed up review. Site review may still be needed |
| **Factory-built / modular** | Homes built in a factory under state oversight. [HCD Factory-Built Housing](https://www.hcd.ca.gov/building-standards/fbh) |
| **Plan check** | The city's review of construction plans (general) |
| **Completeness check** | The city's first check that an application has everything it needs. SB 9 has a 30-day one per HCD's fact sheet |

## The laws

| Term | Meaning |
|---|---|
| **SB 9** | Lot splits and duplexes on single-family lots. Gov Code 65852.21 and 66411.7. See [background](background.md) |
| **SB 684 / SB 1123** | Small-lot subdivisions, 10 or fewer parcels. Gov Code 66499.41 and 65913.4.5. See [background](background.md) |
| **AB 2011** | Housing on commercial corridors. Gov Code 65912.100 to 65912.140 |
| **SB 4** | Housing on land owned by faith organizations and independent colleges. Gov Code 65913.16 |
| **SB 35 / SB 423** | Streamlined ministerial approval for qualifying multifamily projects. Gov Code 65913.4. [HCD guidelines](https://www.hcd.ca.gov/policy-research/docs/SB-35-Guidelines-Update-Final.pdf) |
| **AB 2234** | Post-entitlement permit timelines. Requires cities to post checklists and sample approved applications online. Gov Code 65913.3 |
| **Permit Streamlining Act** | Sets decision deadlines by project type. Gov Code 65950 |
| **Housing Accountability Act** | Limits the grounds on which a city can deny or downsize a housing project. Gov Code 65589.5 |
| **Mitigation Fee Act** | Defines impact fees and says they must be justified. Gov Code 66000 and following |

## The system

| Term | Meaning |
|---|---|
| **HCD** | California Department of Housing and Community Development. The state housing department |
| **Housing Accountability Unit (HAU)** | The part of HCD that sends technical-assistance and violation letters to cities. [Letters dashboard](https://www.hcd.ca.gov/hau/enforcement-letters) |
| **RHNA** | Regional Housing Needs Allocation. The housing target each city is assigned for a planning cycle (general). HCD publishes [6th-cycle progress data](https://data.ca.gov/dataset/rhna-progress-report) |
| **Housing element** | The part of a city's general plan that says how it will meet its housing target. Includes a sites inventory. [HCD page](https://hcd.ca.gov/housing-element/sites-inventory) |
| **Sites inventory** | The list of parcels a city says can take new housing. Parcels may have sold or been built since it was adopted |
| **APR** | Annual Progress Report. Cities report permits, entitlements and completions to HCD each year. [Data on data.ca.gov](https://data.ca.gov/dataset/housing-element-annual-progress-report-apr-data-by-jurisdiction-and-year) |
| **SCAG** | Southern California Association of Governments. Publishes regional parcel, zoning and housing-element map layers |
| **TCAC / HCD Opportunity Maps** | Maps that rate each census tract's access to opportunity, used in fair-housing scoring |
